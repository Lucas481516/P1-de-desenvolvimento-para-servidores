# Sistema de Personagens Dragon Ball

Trabalho acadêmico da disciplina de Programação Orientada a Objetos (P1).

## Descrição

Sistema simples em Java que representa personagens de Dragon Ball
(Goku, Vegeta e Kuririn) utilizando os conceitos básicos de Programação
Orientada a Objetos vistos em aula.

## Objetivo

Demonstrar, de forma prática e simples, a aplicação dos seguintes conceitos
de POO:

- Classe
- Atributos e visibilidade (private)
- Métodos
- Método construtor
- Encapsulamento (getters e setters)
- Herança
- Sobrecarga de método (method overloading)
- Reescrita de método / Override (method overriding)

## Estrutura do projeto

```
 ├── Main.java        -> executa e demonstra o sistema
 ├── Personagem.java  -> classe base
 ├── Saiyajin.java    -> herda de Personagem (Goku e Vegeta)
 └── Humano.java      -> herda de Personagem (Kuririn)
```
